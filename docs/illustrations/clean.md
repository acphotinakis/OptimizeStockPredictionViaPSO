## Key Constraints Visualized

| Constraint | Visual Indicator | Implementation |
|------------|------------------|----------------|
| **Causal forward-fill** | `← T-5 value` | `df.ffill()` only, no `bfill()` |
| **No interpolation** | Gap > 5 → `DISCARD` | No `interpolate()` method used |
| **Sequential validation** | Step 1 → Step 2 arrow | Gap handling BEFORE range checks |
| **Row dropping** | `████ DISCARD ROW ████` | `df.drop()` not imputation |
| **Core column integrity** | `✓ NO NaN values` | Assert `df[OHLCV].isna().sum() == 0` |
