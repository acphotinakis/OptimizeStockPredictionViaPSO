**Issue:** CUDA Out of Memory error during LSTM training  
**Status:** ✅ FIXED  
**Date:** April 6, 2026

## Problem Description

### Error
```
torch.OutOfMemoryError: CUDA out of memory. Tried to allocate 23.17 GiB. 
GPU 0 has a total capacity of 7.92 GiB of which 6.15 GiB is free.
```

### Location
- **File:** `src/models/lstm_model.py`
- **Function:** `LSTMTrainer.fit()`
- **Lines:** 214-215, 273

### Root Cause

The validation set was loaded entirely to GPU memory at once:

```python
# BROKEN CODE (Lines 214-215)
X_val_t = torch.FloatTensor(X_val).to(self.device)  # Loads ALL validation data to GPU!
y_val_t = torch.FloatTensor(y_val).unsqueeze(-1).to(self.device)

# Then in validation loop (Line 273)
val_pred = self.model(X_val_t)  # OOM HERE - trying to process entire validation set
```

**Why it failed:**
- Validation set: ~500K samples × 30 timesteps × 100 features = 6 GB
- GPU capacity: 7.92 GB total
- Already in use: Training model + optimizer states + gradients = ~1.7 GB
- Attempted allocation: 23.17 GB (forward + backward pass)
- **Result:** Out of memory

## Solution

### Fix 1: Batch Validation Processing ✅

**File:** `src/models/lstm_model.py`

**Changes:**

1. **Create validation DataLoader** (after line 212):
```python
# Create validation DataLoader to avoid OOM
val_ds = TensorDataset(
    torch.FloatTensor(X_val),
    torch.FloatTensor(y_val).unsqueeze(-1),
)
val_dl = DataLoader(
    val_ds,
    batch_size=physical_batch_size,  # Same as training
    shuffle=False,
)
```

2. **Batch validation loop** (replace lines 271-274):
```python
# ---- Validation ----
self.model.eval()
val_loss = 0.0
with torch.no_grad():
    for x_val_b, y_val_b in val_dl:
        x_val_b = x_val_b.to(self.device)
        y_val_b = y_val_b.to(self.device)
        val_pred_b = self.model(x_val_b)
        val_loss += self.criterion(val_pred_b, y_val_b).item() * len(x_val_b)
val_loss = val_loss / len(val_ds)
```

**Benefits:**
- ✅ Processes validation in batches (256 samples at a time)
- ✅ Memory usage: ~100 MB per batch vs. 6 GB for entire set
- ✅ No change to validation loss computation (mathematically equivalent)
- ✅ Works with any validation set size

## Prevention

### Code Review Checklist

When writing PyTorch code, always check:

- [ ] Are large tensors batched before moving to GPU?
- [ ] Is DataLoader used for all data processing?
- [ ] Are tensors moved to CPU when not needed?
- [ ] Is memory cleared between epochs?
- [ ] Are gradients detached from history?

### Pattern to Follow

**❌ BAD - Don't do this:**
```python
X_all = torch.FloatTensor(X).to(device)  # Loads entire dataset to GPU
predictions = model(X_all)  # OOM if X is large
```

**✅ GOOD - Do this:**
```python
dataloader = DataLoader(dataset, batch_size=256, shuffle=False)
predictions = []
for x_batch in dataloader:
    x_batch = x_batch.to(device)  # Only one batch at a time
    pred_batch = model(x_batch)
    predictions.append(pred_batch.cpu())  # Move to CPU immediately
predictions = torch.cat(predictions)
```
